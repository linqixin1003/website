# SPECKIT SPECIFICATION

## Feature
优化 Still Alive 中文文章内容为“身体信号”主题体系，并按专家视角重写。

## Goals
- 25 篇中文文章与五大主题类别一致：排便与肛肠、排尿与泌尿、补水与体重、健身与运动、饮食与肠道。
- 内容以“国际顶尖科普专家”语气呈现，强调可执行性与风险识别。
- 中文正文不再出现英文段落（品牌名与链接除外）。
- 入口页中文标题与分类与文章一致。

## Non-Goals
- 不修改英文或其他语言文章内容。
- 不更改文章文件名与路径结构。
- 不重做页面布局或样式体系。

## User Stories
- 作为读者，我能通过文章理解身体信号含义，并知道何时需要就医。
- 作为读者，我能获得可执行的日常建议，而不是泛泛描述。
- 作为产品维护者，我能在入口页看到与文章一致的中文分类与标题。

## Functional Requirements
- 重写 `zh/still-alive-tips/*.html` 25 篇中文文章的正文内容与标题。
- 每篇文章对应其主题与专家身份：
  - 01–06：肛肠科专家
  - 07–10：泌尿外科专家
  - 11–14：饮食科普专家
  - 15–18：健身教练
  - 19–25：肛肠科专家（饮食与肠道）
- 保持原有 HTML 结构（状态栏、hero、content、callout、source）。
- 更新 `still-alive-app-entry.html` 的 `zh` 标题与分类。

## Content Requirements
- 每篇文章包含：
  1. 引言（体现“倾听身体信号”主题）
  2. 核心要点（要点清晰、可量化）
  3. 实操步骤（可执行）
  4. 警示信号/误区（避免延误）
  5. Still Alive 提示（与产品结合）
- 使用医学科普语气，避免诊断性结论。
- 明确提示“持续异常需就医”。

## UI Notes
- 维持当前移动端版式与视觉风格。
- 标题与标签文本使用中文类别名。

## Acceptance Criteria
- 25 篇中文文章全部为中文正文，英文仅限品牌名与链接。
- 入口页中文分类与标题与文章一致。
- 主题与专家定位在内容中可感知。
- 文章阅读体验连贯，段落结构清晰。
