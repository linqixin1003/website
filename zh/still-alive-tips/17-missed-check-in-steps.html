脱水警告信号：从轻度脱水到医疗紧急情况

⚡ TL;DR
  • 轻度脱水会导致口渴、口干和尿液颜色加深——喝水很容易解决。
  • 中度脱水会导致头痛、头晕和疲劳 - 请立即采取行动。
  • 严重脱水是一种医疗紧急情况，伴有神志不清、心跳加快和昏厥 - 请立即寻求帮助。
  • 高危人群包括老人、幼儿和运动员 - 他们需要格外警惕。
  • ORS（口服补液）对于中度脱水比普通水更有效。

脱水不仅仅是感觉有点口渴。这是一种渐进性疾病，会经历多个阶段——从轻微的不便到危及生命的紧急情况。棘手的部分？当您注意到症状时，您的身体已经处于赤字状态。了解每个阶段的警告信号可以帮助您快速采取行动并准确知道何时需要就医。

🟢第一阶段：轻度脱水（体内水分流失 1-3%）

轻度脱水是最早的阶段，我们大多数人都会在没有意识到的情况下经常经历它。您的体重大约会因水而流失 1-3%，对于 70 公斤的人来说，这意味着在没有足够补充的情况下流失大约 0.7 至 2.1 升液体。

✓
口渴：最明显的信号。然而，口渴是一个滞后指标——当您感到口渴时，您已经轻度脱水了。
✓
口腔和嘴唇干燥：当您的身体为更重要的功能保存水分时，唾液分泌会减少。
✓
深黄色尿液：您的肾脏会浓缩尿液以保存水分，使其颜色更深、气味更浓。
✓
尿量减少：上厕所次数比平常少是一个早期危险信号。
✓
轻度疲劳：即使水分减少 1-2%，也会降低注意力并增加疲劳感。
做什么

在接下来的 30 分钟内慢慢喝 250-500 毫升的水。避免一次大量饮用。如果您正在锻炼，请暂停并补充水分。大多数轻度脱水会在摄入充足液体后 30-45 分钟内得到缓解。

🟡第 2 阶段：中度脱水（体内水分流失 3-6%）

在这个阶段，你的身体正在挣扎。您的体重因水而减轻了 3-6%，并且多个器官系统都受到影响。认知功能下降，身体机能直线下降，您的身体开始重新分配资源以保持重要器官的功能。

✓
头痛：脱水会导致大脑暂时收缩并脱离颅骨，从而触发疼痛感受器。这是头痛最常见且最容易被忽视的原因之一。
✓
头晕目眩：血容量减少，流向大脑的血液减少，尤其是在快速站立时。
✓
严重疲劳：当身体进入保护模式时，您的肌肉会失去效率，新陈代谢也会减慢。
✓
皮肤干燥、凉爽：当身体优先考虑内部冷却时，出汗量就会减少。
✓
眼睛凹陷：眼睛周围的组织对液体变化很敏感，并且很早就表现出脱水。
✓
肌肉痉挛：液体流失导致的电解质失衡会引发疼痛性痉挛，尤其是腿部。
✓
尿液颜色非常深或呈琥珀色：尿液浓度非常高、体积小是一个严重的指标。
做什么

现阶段仅用白开水可能还不够。您的身体需要电解质（钠、钾、氯）和水。使用口服补液盐 (ORS)、运动饮料或在家自制 ORS。在 1-2 小时内缓慢而稳定地啜饮。在凉爽的环境中休息。如果症状在 1-2 小时内没有改善，请就医。

🔴第三阶段：严重脱水（体内水分流失超过 6%）

严重脱水是一种医疗紧急情况。此时，您的身体处于危机模式。器官功能受到损害，如果不进行干预，严重脱水可能会导致器官衰竭、癫痫发作、昏迷或死亡。

🚨 如果您发现以下情况，请立即致电紧急服务：
  • 精神错乱或谵妄：大脑没有获得足够的血流和氧气
  • 心跳加快（心动过速）：心脏泵血速度加快，以补偿血容量的减少
  • 快速、浅呼吸：身体正在努力维持氧气水平
  • 昏厥或失去知觉：血压降至危险水平
  • 8 小时以上没有排尿：肾脏正在关闭以保存液体
  • 癫痫发作：严重的电解质失衡可能引发神经系统事件
  • 极度干燥、呈帐篷状的皮肤：挤压时，皮肤会保持凸起状态（肿胀度差）
  • 低血压：收缩压低于 90 mmHg 是危险的

严重脱水需要在医院进行静脉 (IV) 补液。不要尝试在家中进行管理。在等待紧急服务时，让患者躺在阴凉的地方，稍微抬高双腿，如果患者神志清醒且能够吞咽，则小口口服补液盐。

👶 高危人群：谁需要额外警惕？

某些人群更容易脱水，并可能表现出不同的警告信号：

✓
老年人：口渴机制随着年龄的增长而减弱。许多老年人即使脱水也不会感到口渴。利尿剂等药物会增加风险。护理人员应全天定期提供液体。
✓
婴幼儿：相对于体重而言，体表面积越大意味着液体流失得越快。注意湿尿布减少、哭泣时没有眼泪、囟门凹陷（软点）以及异常嗜睡。婴儿脱水可能会在数小时内加剧。
✓
运动员和户外工作者：在炎热的剧烈活动中，大量出汗会导致每小时流失 1-2 升的水。电解质的补充很重要，而不仅仅是水。
✓
慢性病患者：糖尿病、肾脏疾病和心脏病都会影响体液平衡。有些药物会改变口渴感或增加排尿。
✓
孕妇：怀孕期间血容量增加 50%，需要大量液体。孕吐会使保持水分变得困难。

🧪 DIY口服补液（ORS）

世界卫生组织的 ORS 配方是一种全球范围内使用的拯救生命的解决方案。当没有商业产品时，您可以在家制作：

世界卫生组织推荐的 ORS 配方

成分：

1升清洁饮用水

糖6平茶匙（约30克）

1/2茶匙盐（约2.5克）

说明：将糖和盐完全溶解在水中。慢慢地喝——成人每小时大约 200-400 毫升，儿童则少喝。 24 小时后丢弃未使用的溶液。

可选：添加柠檬汁或橙汁以补充钾和风味。

ORS 之所以有效，是因为肠道中的葡萄糖-钠协同转运机制使水比单独的白水吸收得更快。这就是为什么运动饮料同时含有糖和盐——尽管商业 ORS 具有更精确的临床补液配方。

🌞 与热有关的脱水

与热有关的脱水特别危险，因为热病会迅速加剧脱水症状。了解进展至关重要：

中暑当您的身体过热且无法有效冷却时就会发生。症状包括大量出汗、皮肤又冷又湿、恶心、虚弱、脉搏快但微弱。转移到阴凉的地方，松开衣服，穿上凉布，然后喝水或口服补液盐。

中暑是最危险的形式。体温升至 40 摄氏度（104 华氏度）以上。出汗可能会停止，皮肤变热变红，并且出现意识混乱或意识不清。这是危及生命的紧急情况，需要立即就医。致电紧急服务部门，并在等待期间用冰袋敷在颈部、腋窝和腹股沟上，为患者降温。

🛡️预防策略

治疗脱水的最佳方法是永远不要让它达到中度或重度阶段。以下是基于证据的预防策略：

✓
补充水分：在运动或高温户外活动前 2-3 小时喝 400-600 毫升水。
✓
设置提醒：使用手机或应用程序每小时提醒您喝水，特别是如果您是一个容易忘记喝水的人。
✓
监测尿液颜色：检查每次上厕所的情况。目标是淡稻草黄色。
✓
补充失去的水分：每小时进行适度运动，至少喝 500 毫升水。运动前和运动后称重 — 每减掉一公斤就代表大约需要补充 1 升液体。
✓
吃补水食物：水果、蔬菜、汤和酸奶都有助于水分摄入。
✓
高温时避免饮酒：酒精是一种利尿剂，会损害身体调节温度的能力。
✓
保持水可用：携带可重复使用的水瓶。如果水触手可及，您就会喝更多——行为研究一致表明了这一点。

脱水几乎总是可以预防的。通过学习解读身体信号、了解谁面临的风险最大，以及了解如何在每个阶段做出反应，您可以保护自己和周围的人免受这种情况的影响，虽然这种情况很常见，但绝不应掉以轻心。
